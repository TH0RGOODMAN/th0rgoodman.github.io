# hea1 · Personal project site

A small static homepage linking to runnable engineering learning projects.

No framework, build step, analytics or external fonts. Upload `index.html`, `favicon.svg`, `LICENSE` and `assets/` to a static host, or use GitHub Pages from the root of `main`.

The assembly screenshot is generated from the public [Assembly Training Lab](https://github.com/TH0RGOODMAN/assembly-training-lab) application. Project limitations and AI assistance are documented on the page and in the project repository.

The intended custom domain is `hea1.org`; DNS is configured separately after the site works at its default hosting address.
